Demo mode

Connect your Firebase project

The current app runs in demo mode with sample data saved locally in your browser. Follow these steps to connect a free Firebase project.

  1. Create a projectGo to Firebase Console and create a project.
  2. Register a web appIn Project settings, add a web app and copy the Firebase configuration object.
  3. Enable AuthenticationUnder Authentication - Sign-in method, enable Email/Password.
  4. Create Firestore DatabaseOpen Firestore Database and create a database. For a real app, deploy restrictive security rules.
  5. Cloud integration statusFirebase is not connected in this prototype. Replacing config values or switching USE_FIREBASE on will not enable cloud mode; the Firebase SDK and auth/data services must first be implemented and tested.
Security note

Never deploy open Firestore rules. Client-side QR expiry is not sufficient for secure attendance; validate roles, session expiry and duplicate check-ins with trusted rules or a server-side function.
